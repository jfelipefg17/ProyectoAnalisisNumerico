Chapter 1 — Single Variable
Incremental Search
Interval Location
Method Description

Incremental search traverses the domain of f(x) from a point x₀ in steps of size h, detecting all intervals [xₙ, xₙ₊₁] where f changes sign. By the Intermediate Value Theorem, each sign change guarantees at least one root in that subinterval.

Si f(xₙ) · f(xₙ₊₁) < 0 → at least one root exists in [xₙ, xₙ₊₁]

It is an exploration method, not a refinement one. Its result is a set of intervals that are then passed to Bisection or False Position to find the precise root.

AdvantagesDetects multiple roots in a single sweep. Simple to implement. No derivatives required.
LimitationsMay skip roots if h is too large. Does not give the exact root, only the interval. Cost proportional to (b-a)/h.

Chapter 1 — Single Variable
Método de Bisection
Bracketing · Guaranteed Convergence
Method Description

Bisection repeatedly divides the interval [a, b] in half and keeps the half where f changes sign. Requires f(a)·f(b) < 0 (bracketing condition).

xₘ = (a + b) / 2  →  si f(a)·f(xₘ) < 0, b=xₘ; si no, a=xₘ

Convergence is linear: the error halves at each iteration. It is the most robust of the bracketing methods.

Convergence RateLinear. The error at iteration n is ≤ (b−a)/2ⁿ.
Requirementf(a) and f(b) must have opposite signs. f must be continuous on [a,b].

Chapter 1 — Single Variable
False Position (Regula Falsi)
Encuadramiento · Interpolation lineal
Method Description

Instead of taking the midpoint of the interval, false position draws a straight line between (a, f(a)) and (b, f(b)) and uses the x-axis intersection as the new estimate. More efficient than bisection when f is nearly linear.

xₘ = [f(b)·a − f(a)·b] / [f(b) − f(a)]

It can converge very slowly if the function is highly curved (one endpoint stays fixed). In such cases Bisection may actually be faster.

Advantage over bisectionGenerally converges faster by using f information at both endpoints.
Pathological caseIf f is highly curved, one endpoint never moves and convergence becomes slow linear.

Chapter 1 — Single Variable
Fixed Point
Iteration x = g(x)
Method Description

f(x)=0 is rewritten in the form x = g(x) and iterated as xₙ₊₁ = g(xₙ). Convergence critically depends on the choice of g: guaranteed when |g'(x)| < 1 near the fixed point.

xₙ₊₁ = g(xₙ)  →  converge si |g'(x*)| < 1

You must transform f(x)=0 into x=g(x) manually. For example, x²−2=0 can be rewritten as x = 2/x (which diverges) or x = (x + 2/x)/2 (which converges).

Convergence criterionIf |g'(x)| < 1 near the fixed point, the method converges from any nearby starting point.
If it divergesTry a different rewriting of f(x)=0 → x=g(x). The same root may have both convergent and divergent g's.

Newton-Raphson
Quadratic Convergence
Method Description

Uses the tangent to f at the current point to find the next approximation. Converges quadratically when the initial estimate is sufficiently close to the root and f'(x) ≠ 0.

xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ)

The derivative is computed automatically using symbolic differentiation (mathjs). You may also enter f'(x) manually if preferred.

Quadratic ConvergenceEl número de dígitos correctos doubles at each iteration when close to the root.
Fails whenf'(xₙ)=0 (zero denominator), or when x₀ is far from the root and the method oscillates or diverges.

Secant Method
Superlinear · Derivative-Free
Method Description

Approximates Newton's derivative using two previous points, avoiding the need to compute f'(x). Convergence is superlinear with order ≈ 1.618 (golden ratio).

xₙ₊₁ = xₙ − f(xₙ)·(xₙ − xₙ₋₁) / [f(xₙ) − f(xₙ₋₁)]

Requires two initial points x₀ and x₁. Unlike false position, no bracketing is required: x₀ and x₁ can be any distinct values.

Derivative-FreeIdeal when f'(x) is difficult or expensive to compute. Uses finite differences between two iterates.
May failIf f(xₙ)−f(xₙ₋₁)≈0 (denominator near zero), the method diverges.

Chapter 1 — Single Variable
Multiple Roots
Modified Newton · Multiplicity m > 1
Method Description

Standard Newton converges only linearly at roots with multiplicity m > 1 (where f(x*)=f'(x*)=0). This variant uses f'' to restore quadratic convergence.

xₙ₊₁ = xₙ − f(xₙ)·f'(xₙ) / [f'(xₙ)² − f(xₙ)·f''(xₙ)]

Classic example: f(x) = (x−1)² has a double root at x=1. Newton takes many iterations; this method converges quadratically.

When to use itWhen you know the root has multiplicity > 1, meaning f and f' vanish simultaneously.
Automatic Derivativesf' and f'' are computed automatically with mathjs. No need to enter them manually.

Chapter 2 — Linear Systems
Naive Gaussian Elimination
No Pivoting · Direct
Method Description

Reduces the augmented system [A|b] to upper triangular form through elementary row operations, then solves by back substitution. "Naive" means no pivoting: uses the diagonal pivot as-is.

mᵢₖ = aᵢₖ / aₖₖ  →  fᵢ = fᵢ − mᵢₖ · fₖ

Fails if any diagonal pivot is zero. May give imprecise results if pivots are very small (rounding error). For more robustness, use Gauss with partial or total pivoting.

Chapter 2 — Linear Systems
Gauss — Partial Pivoting
Column Pivoting · More Stable
Method Description

Before each elimination step, finds the element with the largest absolute value in the current column (from row k to n) and swaps it to the pivot position. This minimizes rounding error.

Pivot = max|aᵢₖ| for i ≥ k  →  swap rows k and p

This is the standard algorithm in most numerical libraries. More robust than Naive Gauss against nearly singular matrices.

Chapter 2 — Linear Systems
Gauss — Total Pivoting
Row and Column Pivoting · Maximum Stability
Method Description

Finds the element with the largest absolute value in the entire remaining submatrix (not just the column). Swaps both rows and columns, requiring a permutation vector to reorder the final solution.

Pivot = max|aᵢⱼ| for i,j ≥ k  →  swap rows and columns

Maximum numerical stability, but higher computational cost than partial pivoting. Useful for very ill-conditioned matrices.

Chapter 2 — Linear Systems
Simple LU Factorization
Factorization · A = LU
Method Description

Decomposes A = LU where L is lower triangular (with 1s on the diagonal) and U is upper triangular. Solves Ax=b by first solving Ly=b (forward substitution) and then Ux=y (back substitution).

A = LU  →  Ly = b  →  Ux = y

Key advantage: once the LU factorization is computed, solving with different b vectors is very efficient. No pivoting — may fail if there is a zero on the diagonal.

Chapter 2 — Linear Systems
LU Factorization — Partial Pivoting
PA = LU · Stable
Method Description

Incorporates row permutations (matrix P) during factorization: PA = LU. This is the most robust version of LU factorization and the basis for industrial solvers such as LAPACK.

PA = LU  →  Ly = Pb  →  Ux = y

Recommended LU version for general use. Combines the efficiency of reusing the factorization with the stability of partial pivoting.

Chapter 2 — Linear Systems
Doolittle Factorization
LU with Unit L
Method Description

LU variant where the diagonal of L is 1 (unit L) and U contains the scale. Explicit formulas avoid step-by-step elimination, computing L and U directly.

uᵢⱼ = aᵢⱼ − Σ lᵢₖ·uₖⱼ  ·  lᵢⱼ = (aᵢⱼ − Σ lᵢₖ·uₖⱼ) / uⱼⱼ

Equivalente a Simple LU numéricamente, pero la formulación directa es conceptualmente más limpia.

Crout Factorization
LU with Unit U
Method Description

LU variant where the diagonal of U is 1 (unit U) and L contains the scale. Dual of Doolittle.

lᵢⱼ = aᵢⱼ − Σ lᵢₖ·uₖⱼ  ·  uᵢⱼ = (aᵢⱼ − Σ lᵢₖ·uₖⱼ) / lᵢᵢ

The choice between Crout and Doolittle is for numerical convenience; both produce the same solution.

Cholesky Factorization
A = LLᵀ · Symmetric Positive Definite Matrices Only
Method Description

For symmetric positive definite (SPD) matrices, decomposes A = LLᵀ where L is lower triangular. Twice as efficient as LU by exploiting symmetry.

A = LLᵀ  ·  lᵢᵢ = √(aᵢᵢ − Σₖ lᵢₖ²)

Strict requirement: A must be symmetric (aᵢⱼ = aⱼᵢ) and positive definite (all eigenvalues > 0). If A does not meet this, the method fails.

⚠ Matrix A must be symmetric and positive definite. Enter a symmetric matrix (aᵢⱼ = aⱼᵢ) with positive eigenvalues.

Jacobi Method
Iterative · Simultaneous Update
Method Description

Iterative method that updates all variables simultaneously using only values from the previous iteration. Converges if the matrix is strictly diagonally dominant.

xᵢ⁽ᵏ⁺¹⁾ = (bᵢ − Σⱼ≠ᵢ aᵢⱼ·xⱼ⁽ᵏ⁾) / aᵢᵢ

Being independent (uses xⱼ⁽ᵏ⁾ for all j), it is parallelizable. However, it converges more slowly than Gauss-Seidel which uses already-updated values.

Gauss-Seidel
Iterative · Sequential Update
Method Description

Improves on Jacobi by immediately using each newly computed xᵢ within the same iteration. Generally converges twice as fast as Jacobi.

xᵢ⁽ᵏ⁺¹⁾ = (bᵢ − Σⱼ<ᵢ aᵢⱼ·xⱼ⁽ᵏ⁺¹⁾ − Σⱼ>ᵢ aᵢⱼ·xⱼ⁽ᵏ⁾) / aᵢᵢ

The process is sequential (not parallelizable), but the faster convergence compensates. It is the foundation of the SOR method.

Chapter 2 — Linear Systems
SOR — Successive Over-Relaxation
Iterative · Relaxation Factor ω
Method Description

Extension of Gauss-Seidel with a relaxation parameter ω. When 0<ω<1 it is under-relaxation (stabilizes); when 1<ω<2 it is over-relaxation (accelerates). The optimal ω minimizes iterations.

xᵢ⁽ᵏ⁺¹⁾ = (1−ω)·xᵢ⁽ᵏ⁾ + ω·(bᵢ − Σⱼ≠ᵢ aᵢⱼ·x)/aᵢᵢ

ω=1 is exactly Gauss-Seidel. The optimal ω depends on matrix structure; experimenting with values between 1.0 and 1.9 is common practice.

Chapter 3 — Interpolation
Vandermonde Method
Vandermonde Linear System
Method Description

Builds the Vandermonde matrix with columns xⁿ⁻¹, xⁿ⁻², ..., x, 1 and solves the linear system to find the coefficients of the interpolating polynomial of degree n−1.

A·a = y  donde Aᵢⱼ = xᵢⁿ⁻¹⁻ʲ

For n points it builds a unique polynomial of degree ≤ n−1. The Vandermonde matrix is notoriously ill-conditioned for large n (>10 points); in that case Newton or Lagrange is preferable.

Chapter 3 — Interpolation
Interpolation de Newton
Divided Differences
Method Description

Builds the interpolating polynomial using the divided differences table. Newton's form is more convenient than Vandermonde because adding a new point only requires a new column.

P(x) = f[x₀] + f[x₀,x₁](x−x₀) + f[x₀,x₁,x₂](x−x₀)(x−x₁) + ...

The coefficients are the divided differences f[x₀,x₁,...,xₖ] forming the first row of the triangular table.

Chapter 3 — Interpolation
Interpolation de Lagrange
Basis Polynomials · Explicit Form
Method Description

Builds the polynomial as a linear combination of n basis polynomials Lᵢ(x), each equal to 1 at xᵢ and 0 at all other nodes.

P(x) = Σᵢ yᵢ · Lᵢ(x)  donde Lᵢ(x) = Πⱼ≠ᵢ (x−xⱼ)/(xᵢ−xⱼ)

The Lagrange form is conceptually elegant and useful for deriving quadrature formulas. Adding a point requires recomputing all basis polynomials — that is why Newton is more efficient for incremental nodes.
